# SummarizedExperiment7: an S7 implementation of SummarizedExperiment

Implements the `SummarizedExperiment` and `RangedSummarizedExperiment`
interfaces described by the language-agnostic biocspec specification
using the 'S7' object system, as a demonstration that the data structure
is separable from Bioconductor's S4 class system.
